# `examples/`: dados sintéticos para demonstração

Única pasta onde arquivos de dados (`.csv`, `.xlsx`, `.parquet`, `.db`) podem
ser versionados; o `.gitignore` bloqueia esses formatos em qualquer outro lugar.

**Somente dados sintéticos**, gerados por código versionado no próprio projeto,
para que qualquer pessoa possa reproduzi-los e verificar que não há pessoa real.
Preenchido quando os detectores existirem.
