# `tests/`: testes automatizados (pytest)

Espelha a estrutura de `src/lgpd_scan/`. Configuração do pytest no
`pyproject.toml` (Fase 0, passo 4); primeiros testes na **Fase 1**.

Dados de teste: só valores sintéticos, gerados por código ou por funções
auxiliares dos próprios testes. Nada de dado pessoal real, nem "mascarado".
